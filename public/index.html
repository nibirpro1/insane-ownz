Live leaderboard sync

What happens after you save a channel.
1
Board posted and pinned once
Choosing a new channel clears the old pinned message and the bot posts a fresh board there right away.
2
The same message keeps updating
It edits that one pinned message on every tick — it never posts a second board.
3
No edit when nothing changed
If the top 10 is identical to the last tick, the edit is skipped entirely — that is what keeps it spam-free.

Your bot token

Paste it here to build your ready-to-paste .env block. It stays in this browser — nothing is sent anywhere.
DISCORD_TOKEN= GUILD_ID= DASHBOARD_PASSWORD= DATABASE_URL=postgresql://user:pass@host:5432/insane_ownz

Run it on your host

Two commands to install, two to go live.
bun install bunx prisma migrate deploy
bun run deploy-commands bun start

Then, inside Discord

Four steps and everything is live.
1
Invite the bot
Developer portal → OAuth2 → URL generator → scopes bot + applications.commands, then open the link and pick your server.
2
Run /setuproles
Creates the staff and member roles the bot needs, in the right order.
3
Run /setup
Choose your mod-log, welcome, level-up and ticket channels — or set them from the Setup page here.
4
Run /leaderboard live
Posts the pinned live board that keeps updating itself. Done — the pages here start filling with real data.
